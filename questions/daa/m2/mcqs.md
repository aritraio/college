# MCQs

**1. Which searching algorithm checks every single element sequentially until the target is found?**
A) Binary Search
B) Linear Search
C) Interpolation Search
D) Jump Search
**Answer:** B

**2. What is the absolute prerequisite for applying Binary Search to an array?**
A) The array must contain uniform data.
B) The array must be dynamically allocated.
C) The array must be sorted.
D) The array must have an even number of elements.
**Answer:** C

**3. Which sorting algorithm fundamentally relies on the concept of a "pivot" element?**
A) Merge Sort
B) Heap Sort
C) Quick Sort
D) Insertion Sort
**Answer:** C

**4. What is the worst-case time complexity of Merge Sort?**
A) O(n)
B) O(n log n)
C) O(n²)
D) O(log n)
**Answer:** B

**5. Interpolation search is statistically faster than Binary Search ONLY when:**
A) The data is completely random.
B) The data elements are uniformly distributed.
C) The data array is highly skewed to one side.
D) The array size is very small.
**Answer:** B

**6. What is the auxiliary space complexity of Merge Sort?**
A) O(1)
B) O(log n)
C) O(n)
D) O(n log n)
**Answer:** C

**7. In standard Quick Sort (where the last or first element is picked as the pivot), when does the worst-case time complexity of O(n²) occur?**
A) When the array is already sorted (ascending or descending).
B) When the pivot is exactly the median of the array.
C) When the array elements are completely random.
D) When the array size is a prime number.
**Answer:** A

**8. What is the average-case time complexity of Interpolation Search?**
A) O(n)
B) O(log n)
C) O(log (log n))
D) O(1)
**Answer:** C

**9. In Heap Sort, the fundamental algorithmic operation used to maintain the tree structure property after an extraction is called:**
A) Partitioning
B) Merging
C) Splitting
D) Heapify
**Answer:** D

**10. Which of the following algorithms is NOT considered an "in-place" sorting algorithm?**
A) Quick Sort
B) Heap Sort
C) Merge Sort
D) Linear Sort
**Answer:** C
