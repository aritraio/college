# One-Liner Questions

1. **Question:** What is a machine learning algorithm?
**Answer:** A set of mathematical instructions or logic that a computer uses to learn patterns from data without being explicitly programmed.

2. **Question:** Name the primary types of machine learning algorithms.
**Answer:** Supervised learning, unsupervised learning, and reinforcement learning.

3. **Question:** What is a model pipeline?
**Answer:** A sequential, automated set of steps encompassing data collection, preparation, model training, and output generation.

4. **Question:** Define data preparation.
**Answer:** The process of cleaning, formatting, and transforming raw data into a structured format suitable for an algorithm to process.

5. **Question:** Why must we identify relevant data?
**Answer:** To ensure the algorithm learns the actual underlying patterns (signal) rather than random anomalies or irrelevant information (noise).

6. **Question:** What does the machine learning cycle consist of?
**Answer:** The continuous, iterative process of gathering data, preparing it, training a model, evaluating performance, and deploying or refining it.

7. **Question:** What happens inside the machine learning training phase?
**Answer:** The algorithm processes the prepared data, computes errors, and adjusts its internal parameters to minimize those errors.

8. **Question:** What is the fundamental role of an algorithm in ML?
**Answer:** It acts as the computational engine that extracts predictive rules and relationships from datasets.

9. **Question:** What does practical implementation of training algorithms entail?
**Answer:** Writing the code using specific frameworks to execute the mathematical logic of the algorithm against a prepared dataset.

10. **Question:** What is the consequence of skipping data preparation in the pipeline?
**Answer:** The model will likely fail to execute or will produce highly inaccurate predictions (garbage in, garbage out).
