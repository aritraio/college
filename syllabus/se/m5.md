# Software Engineering (BCA50112)
## Module 5: Software Testing and Project Management [12H]

### Syllabus Content
* **Testing & QA**: Software testing and quality assurance, verification vs. validation, testing methodologies (black-box, white-box), and design of test cases.
* **Quality Frameworks**: Product and process quality, quality standards ISO 9000, and Capability Maturity Model (CMM).
* **Project Management**: Need for management, project planning, software size estimation (LOC, function points), cost estimation (COCOMO II model).
* **Scheduling & Risk**: Task sets, network scheduling, earned value analysis, and risk management systems (RMMM). Managing people.
