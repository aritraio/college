# Full-stack Development II (BCA57115)
## Module 2: React CSS, Bootstrap, and Router Concepts [6H(L) + 12H(P)]

### Syllabus Content
* **Styling**: Inline styling, CSS stylesheet, CSS modules, styled-components, adding Bootstrap for React, React Bootstrap package.
* **React Table**: Installation and use of react-table.
* **React Router**: Installing and setting up React Router, configuring router routes.
* **Props & State**: Concept of props, use of props, passing props to child components, creating reusable components, props validation, concept of state, state rules, use of state.
* **Practical**: Implementation of React CSS styling (inline, modules, styled-components), React Bootstrap, and React Router.
