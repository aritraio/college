# MCQs

**1. Which design concept refers to hiding internal implementation details and showing only the essential features?**
A) Refinement
B) Abstraction
C) Coupling
D) Architecture
**Answer:** B

**2. Which of the following is a standard feature of a modern Graphical User Interface (GUI)?**
A) Command-line prompts
B) Syntax highlighting
C) Scroll bars
D) Machine code
**Answer:** C

**3. What is the primary purpose of establishing coding standards in a development team?**
A) To make the software run faster
B) To automate the testing process
C) To improve code readability and maintainability
D) To eliminate the need for software architecture
**Answer:** C

**4. In software design, what does "cohesion" measure?**
A) The degree of interdependence between different modules
B) The visual appeal of the user interface
C) The functional strength or relatedness of elements within a single module
D) The execution speed of the program
**Answer:** C

**5. Which combination is universally considered the hallmark of functionally independent modules?**
A) Low cohesion, high coupling
B) High cohesion, high coupling
C) Low cohesion, low coupling
D) High cohesion, low coupling
**Answer:** D

**6. Which of the following best describes "information hiding"?**
A) Encrypting user passwords in the database
B) Designing modules so their internal data and procedures are inaccessible to external modules
C) Removing comments from source code
D) Hiding system files from the end-user
**Answer:** B

**7. In the context of UI & Control Design, what is a primary cause of high user error rates?**
A) Consistent placement of navigation buttons
B) Overloading the user's short-term memory with complex input requirements
C) Implementing functional independence
D) Providing descriptive error messages
**Answer:** B

**8. What does "refinement" refer to in software design?**
A) The process of selecting the most modern programming language
B) Designing the icons and panels for the GUI
C) A top-down elaboration process that provides increasing levels of detail for an abstraction
D) Refactoring code to meet new coding standards
**Answer:** C

**9. When selecting development tools and programming languages, which factor is most critical?**
A) The popularity of the language on coding forums
B) The personal preference of the junior developers
C) Alignment with the chosen software architecture and the specific problem domain
D) Ensuring the language requires no coding standards
**Answer:** C

**10. What is a "design pattern" in software engineering?**
A) A specific color scheme used in GUI design
B) A reusable solution to a commonly occurring problem within a given context in software design
C) The specific sequence of characters required to compile a program
D) A deprecated method of organizing code
**Answer:** B
