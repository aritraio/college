# Flashcards

**Flashcard 1**
*Front:* Divide-and-Conquer: Recurrence Relation for Standard Matrix Multiplication
*Back:* $T(n) = 8T(n/2) + O(n^2)$

**Flashcard 2**
*Front:* Greedy: Sorting criterion for Fractional Knapsack
*Back:* Sort all items in descending order of their value-to-weight ratio (Value/Weight).

**Flashcard 3**
*Front:* Dynamic Programming vs. Divide-and-Conquer
*Back:* Divide-and-Conquer splits problems into independent, non-overlapping subproblems. Dynamic programming is used when subproblems overlap, storing results to avoid redundant calculations.

**Flashcard 4**
*Front:* Dynamic Programming: Matrix Chain Multiplication Objective
*Back:* Find the optimal placement of parentheses to minimize total scalar multiplications. It does *not* actually multiply the matrices.

**Flashcard 5**
*Front:* Backtracking: N-Queens Constraints
*Back:* No two queens can share the same row, column, or diagonal on an $N \times N$ chessboard.

**Flashcard 6**
*Front:* String Matching: Worst-case Time Complexity of Naive vs. KMP
*Back:* Naive: $O(m \times n)$
KMP: $O(n + m)$
