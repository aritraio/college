# One-Liner Questions

1. **Question:** What is an arrow function?
**Answer:** A concise syntax for writing JavaScript functions, utilizing the `=>` token.

2. **Question:** What is a synthetic event in React?
**Answer:** A cross-browser wrapper around the browser's native event system.

3. **Question:** How do you bind an input field to React state?
**Answer:** By setting the input's `value` prop to the state variable and updating it via the `onChange` event handler.

4. **Question:** Name a standard free React developer tool.
**Answer:** The "React Developer Tools" browser extension available for Chrome and Firefox.

5. **Question:** Define "deployment" in the context of React.
**Answer:** The process of transferring a bundled React application to a web server so it can be accessed over the internet.

6. **Question:** What is the `onChange` event handler used for?
**Answer:** It triggers a function every time the value of an input field is modified by the user.

7. **Question:** What is the `onSubmit` event handler used for?
**Answer:** It triggers a function when a form is submitted, usually tied to the `<form>` element.

8. **Question:** What command creates an optimized production build in Create React App or Vite?
**Answer:** `npm run build`

9. **Question:** What does the "Components" tab in React DevTools allow you to do?
**Answer:** It allows you to view the tree of React components on the page and inspect their current props and state.

10. **Question:** Why should you not deploy the development version of a React app?
**Answer:** Because it contains unoptimized code, large source maps, and warnings that drastically reduce performance and expose source logic.
