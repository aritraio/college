# Full-stack Development II (BCA57115)
## Module 4: API Request with React and Data Binding [6H(L) + 12H(P)]

### Syllabus Content
* **React API Integration**: Fetching data, sending data, creating an API using PHP & MySQL.
* **AngularJS Intro**: Introduction to AngularJS, MVC architecture, conceptual overview, setting up the environment, first application understanding and attributes.
* **AngularJS Expressions**: Number and string expressions, object binding and expressions, working with arrays.
* **Data Binding**: Understanding data binding in AngularJS.
* **Practical**: Implementation of API requests and related applications.
