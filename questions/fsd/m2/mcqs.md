# MCQs

**1. Which of the following is a valid method for styling components in React?**
A) Inline styling
B) CSS Modules
C) styled-components
D) All of the above
**Answer:** D

**2. What is the primary purpose of 'props' in React?**
A) To manage internal component memory
B) To pass data from a parent component to a child component
C) To configure routing paths
D) To format tables
**Answer:** B

**3. Which of the following statements about React 'state' is true?**
A) State is immutable and cannot be changed.
B) State is passed from parent to child.
C) State holds information that may change over the lifecycle of a component.
D) State is primarily used for CSS styling.
**Answer:** C

**4. How does the React Bootstrap package fundamentally differ from adding standard Bootstrap via a CDN?**
A) React Bootstrap uses its own custom CSS instead of standard Bootstrap CSS.
B) React Bootstrap replaces standard Bootstrap JavaScript dependencies (like jQuery) with native React components.
C) React Bootstrap only supports inline styling.
D) React Bootstrap is incompatible with CSS Modules.
**Answer:** B

**5. When configuring routes in React Router, which element is responsible for rendering a specific UI when the URL matches a given path?**
A) `<Router>`
B) `<Link>`
C) `<Route>`
D) `<Navigation>`
**Answer:** C

**6. What is the main advantage of using CSS Modules over a standard CSS stylesheet in a React application?**
A) Faster compilation times.
B) It allows writing CSS directly inside JavaScript objects.
C) It automatically scopes class names locally to prevent global naming conflicts.
D) It eliminates the need for CSS entirely.
**Answer:** C

**7. Which library is explicitly required for installation and use when building data grids according to this module?**
A) react-grid
B) react-data-table
C) bootstrap-table
D) react-table
**Answer:** D

**8. Which of the following violates the fundamental rules of React state?**
A) Initializing state with an empty string.
B) Modifying the state object directly (e.g., `state.value = 'new'`).
C) Passing state down to child components as props.
D) Triggering a re-render by updating the state.
**Answer:** B

**9. What is the purpose of implementing props validation in a React application?**
A) To enforce type checking, ensuring the component receives the correct data types and mandatory props.
B) To encrypt the data being passed between components.
C) To convert state into props automatically.
D) To validate form inputs before submission.
**Answer:** A

**10. Which underlying JavaScript feature allows `styled-components` to process CSS within a JavaScript file?**
A) Arrow functions
B) Tagged template literals
C) Object destructuring
D) Promises
**Answer:** B
