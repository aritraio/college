# Flashcards

**Flashcard 1**
*Front:* Supervised vs. Unsupervised Learning
*Back:* Supervised uses labeled data (known inputs/outputs); Unsupervised uses unlabeled data (finds hidden structures).

**Flashcard 2**
*Front:* Reinforcement Learning Core Loop
*Back:* Agent takes an Action -> Environment changes State -> Agent receives a Reward/Penalty -> Agent updates policy.

**Flashcard 3**
*Front:* Data Preprocessing (Purpose)
*Back:* "Garbage In, Garbage Out." It standardizes raw data, handles missing values, and encodes text so algorithms can process the mathematical inputs effectively.

**Flashcard 4**
*Front:* Neural Network (Structure)
*Back:* Composed of an Input Layer, one or more Hidden Layers (where computation occurs), and an Output Layer.

**Flashcard 5**
*Front:* Model Building (Training Phase)
*Back:* Feeding preprocessed data into an algorithm to mathematically adjust its internal weights and learn patterns.

**Flashcard 6**
*Front:* Model Evaluation (Testing Phase)
*Back:* Assessing a trained model's performance on a completely separate dataset to prove it can generalize, not just memorize.

**Flashcard 7**
*Front:* Data Mining vs. Machine Learning
*Back:* Data Mining extracts historical patterns for human analysis; Machine Learning builds predictive models for autonomous future decision-making.

**Flashcard 8**
*Front:* Tying Methods to Business Outcomes
*Back:* Translating technical metrics (like precision/recall) into business metrics (like cost savings, revenue generated, or risk mitigated).
