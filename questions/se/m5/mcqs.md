# MCQs

**1. Which question is primarily addressed by Software Validation?**
A) Are we building the product right?
B) Are we building the right product?
C) Is the code efficient?
D) Does the software meet the ISO standard?
**Answer:** B

**2. Which testing methodology focuses exclusively on the inputs and outputs without examining the internal logic of the code?**
A) White-box testing
B) Glass-box testing
C) Black-box testing
D) Integration testing
**Answer:** C

**3. What does CMM stand for in the context of software quality frameworks?**
A) Capability Maturity Model
B) Comprehensive Measurement Model
C) Cost Management Metric
D) Capability Management Method
**Answer:** A

**4. In software size estimation, what does LOC measure?**
A) Lack of Cohesion
B) Lines of Code
C) Levels of Complexity
D) Logical Object Classes
**Answer:** B

**5. Which of the following requires the tester to have detailed knowledge of the software's source code to design test cases?**
A) Black-box testing
B) Acceptance testing
C) White-box testing
D) Requirements validation
**Answer:** C

**6. ISO 9000 primarily focuses on ensuring quality in the:**
A) Code syntax
B) Testing environment
C) Software process
D) Hardware configuration
**Answer:** C

**7. COCOMO II is a model specifically utilized for:**
A) Software size estimation
B) Software cost estimation
C) Risk management
D) Network scheduling
**Answer:** B

**8. What is the primary function of Earned Value Analysis (EVA) in project scheduling?**
A) To estimate the initial cost of a project
B) To track project progress and performance against the project plan
C) To identify technical risks in the software architecture
D) To calculate the total Lines of Code (LOC)
**Answer:** B

**9. In risk management, what do the letters in RMMM stand for?**
A) Risk Measurement, Mitigation, and Maintenance
B) Risk Mitigation, Monitoring, and Management
C) Resource Management, Monitoring, and Maintenance
D) Resource Mitigation, Measurement, and Modeling
**Answer:** B

**10. Which software size estimation metric is generally considered independent of the programming language used?**
A) Lines of Code (LOC)
B) Earned Value
C) Function Points
D) Task Sets
**Answer:** C
