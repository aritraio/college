# Short Answer Questions

**1. Distinguish between hardware wear-out and software deterioration. (3 marks)**
**Answer:** Hardware components are subject to physical degradation over time due to environmental factors like dust, vibration, and temperature extremes, commonly represented by the "bathtub curve" (high early failure, low steady failure, high wear-out failure). Software is logical and does not physically wear out. However, it deteriorates. As a software program undergoes continuous evolution, maintenance, and patching to meet new requirements, its original design structure degrades, making it more prone to errors and harder to maintain.

**2. List and briefly explain the four core quality attributes of good software. (4 marks)**
**Answer:**
1. **Maintainability:** The architecture and code must allow for future changes and evolution to meet shifting user needs.
2. **Dependability/Security:** The software must be reliable, safe, and secure, preventing damage upon failure and resisting malicious attacks.
3. **Efficiency:** The system must utilize hardware resources (CPU, memory, power) optimally without waste.
4. **Acceptability:** The software must be intuitive, understandable, and compatible with the target user's existing systems and workflows.

**3. Describe the three key challenges currently faced by software engineers. (3 marks)**
**Answer:**
1. **Heterogeneity:** Software must cope with running across diverse platforms, varying network protocols, and mixed computing environments.
2. **Rapid Delivery:** Businesses demand shorter development cycles, requiring engineers to deliver robust software quickly without sacrificing quality.
3. **Security and Trust:** With increasing cyber threats, engineers must ensure software protects user data and operates securely to maintain user trust.

**4. Explain the concept of Systems Engineering and how software fits into it. (4 marks)**
**Answer:** Systems engineering is an interdisciplinary field focused on the design, integration, and management of complex overarching systems over their life cycles. This includes hardware, infrastructure, processes, and people. Software engineering is a specialized subset of this field. In this context, software acts as a highly complex sub-system that must interface seamlessly with hardware and other sub-systems to ensure the overall system functions correctly.

**5. Define and differentiate between System Software and Embedded Software. (3 marks)**
**Answer:** System software is a collection of programs written to service and support other programs (e.g., Operating Systems, Compilers, File management tools). It interacts heavily with hardware and provides a platform for applications. Embedded software, conversely, resides within a specific product or physical system (e.g., a microwave keypad, automotive braking system) to control its specific functions and features. While system software is broad and foundational, embedded software is highly specialized and localized to a device.
