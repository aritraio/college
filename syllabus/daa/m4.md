# Design and Analysis of Algorithm (BCA50113)
## Module 4: Graph and Tree Algorithms [16H]

### Syllabus Content
* **Graph Traversals**: Depth First Search (DFS) and Breadth First Search (BFS).
* **Shortest Path**: Dijkstra's algorithm, Bellman-Ford algorithm, Floyd-Warshall algorithm.
* **Spanning Trees**: Disjoint set data structures, Prim's and Kruskal's algorithms.
