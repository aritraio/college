# Flashcards

**Flashcard 1**
*Front:* Waterfall Model
*Back:* A plan-driven model consisting of separate and distinct phases of specification, design, implementation, testing, and deployment.

**Flashcard 2**
*Front:* Spiral Model
*Back:* A framework driven by risk assessment; represented as a spiral where each loop represents a phase of the software process.

**Flashcard 3**
*Front:* Extreme Programming (XP)
*Back:* An agile framework emphasizing technical practices like pair programming, test-driven development (TDD), continuous integration, and frequent small releases.

**Flashcard 4**
*Front:* Software Prototyping
*Back:* Creating an incomplete, early version of a software program to explore requirements, demonstrate feasibility, and gather user feedback.

**Flashcard 5**
*Front:* Incremental Delivery
*Back:* The process of dividing the product into smaller, usable pieces, delivering the core functionalities first and adding features in subsequent releases.

**Flashcard 6**
*Front:* CBSE (Component-Based Software Engineering)
*Back:* An approach focused on integrating existing, commercially off-the-shelf (COTS) components to build a system rather than coding from scratch.

**Flashcard 7**
*Front:* RAD (Rapid Application Development)
*Back:* A development lifecycle that prioritizes rapid prototyping, iterative delivery, and heavy user involvement to accelerate software creation.

**Flashcard 8**
*Front:* CASE Tools Classification
*Back:* Tools can be classified by function (e.g., testing, design), by process phase supported, or by integration level (individual tools, workbenches, or integrated environments).
