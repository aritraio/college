# One-Liner Questions

1. **Question:** Define Linear Search.
**Answer:** An algorithm that iterates through an array sequentially, checking each element against the target value until a match is found or the array ends.

2. **Question:** State the core condition required for Binary Search.
**Answer:** The data structure must be sorted before the algorithm can be applied.

3. **Question:** What algorithm paradigm do Quick Sort and Merge Sort utilize?
**Answer:** The Divide and Conquer strategy.

4. **Question:** Define the role of the pivot in Quick Sort.
**Answer:** It acts as a reference value to partition the array, ensuring all elements smaller are placed to its left and all elements larger are placed to its right.

5. **Question:** What is a max-heap?
**Answer:** A complete binary tree data structure where the value of every parent node is greater than or equal to the values of its child nodes.

6. **Question:** State the worst-case time complexity of Heap Sort.
**Answer:** O(n log n).

7. **Question:** Why is Merge Sort considered a "stable" sort?
**Answer:** It preserves the relative, original order of equal elements in the final sorted output.

8. **Question:** What is the mathematical formula used to estimate the position in Interpolation Search?
**Answer:** $pos = low + \left[ \frac{(x - arr[low]) \times (high - low)}{arr[high] - arr[low]} \right]$

9. **Question:** What defines an in-place sorting algorithm?
**Answer:** An algorithm that requires a small, constant amount of extra memory space (O(1)) to sort the data, modifying the original array directly.

10. **Question:** When does the best-case complexity of Quick Sort occur?
**Answer:** It occurs when the partition process perfectly divides the array into two equal halves every single time (O(n log n)).
