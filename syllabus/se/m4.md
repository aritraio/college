# Software Engineering (BCA50112)
## Module 4: Software Design and Development Tools [10H]

### Syllabus Content
* **Design Concepts**: Abstraction, architecture, patterns, modularity, cohesion, coupling, information hiding, functional independence, and refinement.
* **UI & Control Design**: Input and control design, user interface design, elements of good design, design issues, and features of modern GUI (menus, scroll bars, windows, buttons, icons, panels, error messages, etc.).
* **Coding Standards**: Programming languages and development tools, selecting languages and tools, good programming practices, and coding standards.
