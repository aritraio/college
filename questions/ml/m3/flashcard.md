# Flashcards

**Flashcard 1**
*Front:* Machine Learning Algorithm
*Back:* The mathematical procedure or logic used to find patterns in data and build predictive models.

**Flashcard 2**
*Front:* Model Pipeline
*Back:* The automated, sequential flow of data from raw input, through data preparation, to model training and output.

**Flashcard 3**
*Front:* Data Preparation
*Back:* The essential step of cleaning, normalizing, and formatting data before feeding it to an algorithm.

**Flashcard 4**
*Front:* Identifying Relevant Data
*Back:* The process of feature selection; choosing the variables most predictive of the target outcome while discarding noise.

**Flashcard 5**
*Front:* Machine Learning Cycle
*Back:* The iterative loop: Define Problem -> Gather/Identify Data -> Prepare Data -> Train Model -> Evaluate -> Deploy/Refine.

**Flashcard 6**
*Front:* Practical Implementation
*Back:* Translating algorithmic theory into executable code to train a model on a dataset.
