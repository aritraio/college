# MCQs

**1. What is the correct syntax for a React arrow function?**
A) `function myFunc() => {}`
B) `const myFunc = () => {}`
C) `const myFunc => () {}`
D) `=> function myFunc() {}`
**Answer:** B

**2. Which HTML element is fundamentally used to wrap user input controls?**
A) `<div>`
B) `<input>`
C) `<form>`
D) `<group>`
**Answer:** C

**3. What is the primary purpose of React Developer Tools?**
A) To write React code in the browser
B) To deploy React applications directly to a server
C) To inspect the React component hierarchy and state/props
D) To format HTML and CSS files automatically
**Answer:** C

**4. How are event handlers typically named in React?**
A) lowercase (e.g., `onclick`)
B) camelCase (e.g., `onClick`)
C) snake_case (e.g., `on_click`)
D) PascalCase (e.g., `OnClick`)
**Answer:** B

**5. How do you prevent a form from causing a full page reload upon submission in React?**
A) `event.stopReload()`
B) `event.preventDefault()`
C) `event.stopPropagation()`
D) `return false;`
**Answer:** B

**6. In a controlled component, where does the form data reside?**
A) In the DOM
B) In the React component's state
C) In the browser's local storage
D) In the server's database
**Answer:** B

**7. Why are arrow functions heavily used for event handlers in React?**
A) They run faster than regular functions in the V8 engine.
B) They automatically prevent default form submissions.
C) They do not bind their own `this`, inheriting it from the enclosing scope.
D) They are the only function type allowed inside JSX.
**Answer:** C

**8. What must you generate before deploying a React application to a production server?**
A) A development server instance
B) A Docker container
C) A bundled and minified production build
D) A secondary Git branch
**Answer:** C

**9. When deploying a React application, which folder is typically uploaded to the server?**
A) `/src`
B) `/public`
C) `/node_modules`
D) `/build` (or `/dist`)
**Answer:** D

**10. How can you efficiently handle state changes for multiple form inputs using a single event handler?**
A) You cannot; each input requires its own handler.
B) By using the `name` attribute of the input to dynamically update the corresponding state property.
C) By wrapping all inputs in a single `<div>` and tracking mouse clicks.
D) By relying entirely on uncontrolled components and `ref`s.
**Answer:** B
