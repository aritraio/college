# MCQs

**1. Which data structure is fundamentally used to implement Breadth First Search (BFS)?**
A) Stack
B) Queue
C) Priority Queue
D) Linked List
**Answer:** B

**2. What is the primary objective of a Minimum Spanning Tree (MST) algorithm?**
A) To find the shortest path between two specific nodes.
B) To connect all vertices in a graph with the maximum possible edge weight.
C) To connect all vertices in a graph without cycles and with the minimum total edge weight.
D) To traverse every edge exactly once.
**Answer:** C

**3. Which graph traversal method explores as far as possible along each branch before backtracking?**
A) Breadth First Search
B) Depth First Search
C) Dijkstra's Algorithm
D) Kruskal's Algorithm
**Answer:** B

**4. Under which condition does Dijkstra's algorithm fail to guarantee the correct shortest path?**
A) When the graph contains cycles.
B) When the graph is undirected.
C) When the graph contains negative weight edges.
D) When the graph is completely disconnected.
**Answer:** C

**5. What algorithm paradigm does Kruskal's algorithm utilize to find a Minimum Spanning Tree?**
A) Dynamic Programming
B) Divide and Conquer
C) Backtracking
D) Greedy Method
**Answer:** D

**6. The Floyd-Warshall algorithm is designed to solve which of the following problems?**
A) Single-source shortest path
B) All-pairs shortest path
C) Minimum Spanning Tree
D) Graph coloring
**Answer:** B

**7. In a disjoint-set data structure, which optimization technique flattens the structure of the tree directly to the root whenever `Find` is called?**
A) Union by rank
B) Path compression
C) Tree balancing
D) Edge relaxation
**Answer:** B

**8. For a graph with $V$ vertices and $E$ edges, what is the maximum number of times the Bellman-Ford algorithm iterates through all edges to find shortest paths (assuming no negative cycles)?**
A) $V$
B) $V - 1$
C) $E - 1$
D) $V + E$
**Answer:** B

**9. What is the time complexity of Dijkstra's algorithm when implemented using an adjacency list and a Binary Min-Heap?**
A) $O(V^2)$
B) $O(E \log V)$
C) $O((V + E) \log V)$
D) $O(V \log E)$
**Answer:** C

**10. What is the time complexity of the Floyd-Warshall algorithm?**
A) $O(V^2)$
B) $O(V^3)$
C) $O(V^2 \log V)$
D) $O(V E)$
**Answer:** B
