# Long Answer Questions

**1. Detail the AdaBoost (Adaptive Boosting) algorithm. Include the mathematical intuition behind the instance weight updates.**
**Answer:**
AdaBoost builds a strong classifier by combining multiple weak classifiers (typically decision stumps) sequentially. The core logic relies on heavily weighting difficult-to-classify instances.

**Algorithm Steps:**
1. Initialize the weights for all $N$ training instances equally: $w_i = \frac{1}{N}$ for $i = 1, \dots, N$.
2. For each iteration $t = 1 \dots T$:
   * Train a weak classifier $h_t(x)$ on the training data using the current weights $w_i$.
   * Calculate the weighted error rate $\epsilon_t$ of the classifier. If $\epsilon_t \ge 0.5$, stop or re-initialize.
   * Calculate the classifier's importance/weight $\alpha_t$:
     $$\alpha_t = \frac{1}{2} \ln \left( \frac{1 - \epsilon_t}{\epsilon_t} \right)$$
     *(Logic: Lower error results in a higher $\alpha_t$, giving this model more say in the final vote).*
   * Update the instance weights. For each instance $i$:
     $$w_i^{(t+1)} = w_i^{(t)} \exp(-\alpha_t y_i h_t(x_i))$$
     *(Logic: If the prediction $h_t(x_i)$ matches the true label $y_i$, the exponent is negative, decreasing the weight. If wrong, the exponent is positive, increasing the weight).*
   * Normalize the new weights so they sum to 1.
3. **Final Prediction:** Combine the weak classifiers using a weighted majority vote:
   $$H(x) = \text{sign} \left( \sum_{t=1}^T \alpha_t h_t(x) \right)$$


**2. Explain the Random Forest algorithm in detail. Focus on the two key mechanisms that ensure the base trees are de-correlated.**
**Answer:**
Random Forest is an ensemble learning method that operates by constructing a multitude of decision trees at training time. It expands upon standard Bagging by introducing feature randomness, which is critical for model performance.

**Mechanisms for De-correlation:**
1. **Bootstrap Aggregating (Bagging):**
   * If the original dataset has $N$ rows, Random Forest creates a new dataset of size $N$ by sampling from the original data *with replacement*.
   * This means roughly 63.2% of the original data ends up in a given bootstrap sample, while the remaining 36.8% (the Out-of-Bag data) is left out.
   * Each tree is trained on a different bootstrap sample. Because the training data differs slightly, the resulting trees differ, reducing the overall variance when averaged.
2. **Random Subspace Method (Feature Selection):**
   * In a standard decision tree, the algorithm searches *all* available features at every node to find the best split.
   * In a Random Forest, at each node, the algorithm is restricted to searching a random subset of features (often $\sqrt{p}$ where $p$ is the total number of features).
   * **Why this matters:** If there is one highly dominant feature in the dataset, a standard bagging approach will still result in all trees choosing that dominant feature at the root node, making the trees highly correlated. Forcing the trees to look at different random subsets ensures they find different structural patterns, truly de-correlating the ensemble.

**Prediction:** For classification, the forest outputs the mode of the classes produced by individual trees. For regression, it outputs the mean prediction.


**3. Discuss the practical implementation and evaluation of a Stacking ensemble. Address the risk of data leakage and how cross-validation mitigates it.**
**Answer:**
Stacking (Stacked Generalization) is highly effective, but its practical implementation is prone to severe data leakage if the meta-learner is trained on the same exact data used to train the base models.

**The Data Leakage Problem:**
If you train Base Model A on dataset X, and then get Model A to predict on dataset X, the predictions will be overly optimistic (due to overfitting). If you feed these optimistic predictions into the Meta-Learner, the Meta-Learner will learn biased weights and fail completely on unseen data.

**Practical Implementation using Cross-Validation (K-Fold Strategy):**
To evaluate and implement stacking properly, you must use out-of-fold predictions.
1. Divide the training dataset into $K$ folds (e.g., 5 folds).
2. **Base Model Training:** For each base model, train it on $K-1$ folds and predict on the 1 held-out fold. Repeat this $K$ times until you have out-of-fold predictions for the entire training set.
3. Now, every instance in the training set has a prediction generated by a model that *did not see that instance during training*.
4. **Meta-Learner Training:** Use these clean, out-of-fold predictions as the input features ($X$) and the actual labels as the target ($Y$) to train your meta-learner.
5. **Test Set Inference:** When new data arrives, run it through all the base models (which are now retrained on the *entire* training set). Take those outputs and feed them into the trained meta-learner for the final prediction.

**Evaluation:** Practically, ensemble models are evaluated by comparing their metrics (Accuracy, F1, ROC-AUC) against the strongest single base model. If a highly complex Stacking model only yields a 0.01% improvement over a simple Random Forest, the computational overhead and latency are usually not justified for production.
