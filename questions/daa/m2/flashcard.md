# Flashcards

**Flashcard 1**
*Front:* Linear Search (Worst Case Time Complexity)
*Back:* O(n)

**Flashcard 2**
*Front:* Binary Search (Worst Case Time Complexity)
*Back:* O(log n)

**Flashcard 3**
*Front:* Interpolation Search (Average Case Time Complexity)
*Back:* O(log (log n))

**Flashcard 4**
*Front:* Merge Sort (Time Complexity - All Cases)
*Back:* O(n log n)

**Flashcard 5**
*Front:* Merge Sort (Space Complexity)
*Back:* O(n)

**Flashcard 6**
*Front:* Quick Sort (Worst Case Time Complexity)
*Back:* O(n²)

**Flashcard 7**
*Front:* Quick Sort (Space Complexity - Average)
*Back:* O(log n) due to recursive call stack.

**Flashcard 8**
*Front:* Heap Sort (Time Complexity - All Cases)
*Back:* O(n log n)
