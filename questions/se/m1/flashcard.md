# Flashcards

**Flashcard 1**
*Front:* The 3 Configuration Components of Software
*Back:* Programs (instructions), Data Structures (enables programs to manipulate information), and Documentation (describes operation and use).

**Flashcard 2**
*Front:* Hardware Failure vs. Software Failure
*Back:* Hardware suffers from physical "wear-out" (environmental factors). Software suffers from "deterioration" (logical degradation due to constant modifications).

**Flashcard 3**
*Front:* 4 Essential Quality Attributes of Good Software
*Back:* Maintainability, Dependability/Security, Efficiency, Acceptability.

**Flashcard 4**
*Front:* Software Engineering vs. Systems Engineering
*Back:* Systems engineering designs the entire system (hardware, software, infrastructure). Software engineering is focused strictly on the software, which acts as a sub-system within the larger architecture.

**Flashcard 5**
*Front:* Heterogeneity Challenge
*Back:* Developing software that can reliably function across a wide mix of different devices, operating systems, and network configurations.

**Flashcard 6**
*Front:* System Software
*Back:* Programs written to service other programs (e.g., compilers, operating systems).

**Flashcard 7**
*Front:* Product-Line Software
*Back:* A generalized software framework designed to be tailored to specific customers in a particular market segment (e.g., inventory management systems).

**Flashcard 8**
*Front:* Software Dependability
*Back:* A quality attribute covering reliability, security, and safety; ensuring the system doesn't cause physical/economic damage upon failure and blocks malicious users.
