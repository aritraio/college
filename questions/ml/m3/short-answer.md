# Short Answer Questions

**1. Briefly explain the role of algorithms inside machine learning.**
**Answer:** Algorithms act as the core engine of machine learning. Instead of relying on explicit, hardcoded instructions, ML algorithms use statistical methods and mathematical logic to analyze input data, identify underlying patterns, and autonomously build a model capable of making predictions or decisions on new, unseen data.

**2. List and briefly define the three main types of machine learning algorithms.**
**Answer:**
* **Supervised Learning:** Algorithms learn from labeled training data to predict outcomes.
* **Unsupervised Learning:** Algorithms analyze unlabeled data to find hidden structures or clusters.
* **Reinforcement Learning:** Algorithms learn by interacting with an environment, receiving rewards or penalties for actions to maximize a specific goal.

**3. Why is data preparation considered a critical step in the model pipeline?**
**Answer:** Raw data is often incomplete, inconsistent, or contains errors. Data preparation cleans this data, handles missing values, and formats it (e.g., normalization, encoding) so the algorithm can mathematically process it. Without proper preparation, the algorithm cannot learn effectively, leading to poor model performance.

**4. Describe what is meant by "identifying relevant data" and why it matters.**
**Answer:** Identifying relevant data means selecting the specific features or variables that actually influence the outcome you are trying to predict. It matters because feeding an algorithm irrelevant data introduces noise, increases computational overhead, and can cause the model to learn incorrect associations, reducing its accuracy.

**5. Outline the fundamental steps of the machine learning cycle.**
**Answer:** The ML cycle is iterative and typically includes: identifying the problem, gathering and identifying relevant data, data preparation (cleaning/formatting), training the model using an algorithm, evaluating the model's accuracy, and finally deploying it. The cycle repeats to refine the model over time.
