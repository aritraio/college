# MCQs

**1. Which of the following accurately represents the three configuration components of software?**
A) Code, Hardware, Users
B) Programs, Data Structures, Documentation
C) System software, Application software, Embedded software
D) Design, Testing, Maintenance
**Answer:** B

**2. Which software type resides within a product or system to control its specific functions and features?**
A) System software
B) Web applications
C) Embedded software
D) Product-line software
**Answer:** C

**3. What is the fundamental difference in the failure curves of hardware and software?**
A) Hardware deteriorates due to change; software wears out over time.
B) Both hardware and software wear out physically.
C) Hardware wears out due to environmental factors; software deteriorates due to continuous changes and updates.
D) Software has a higher physical failure rate than hardware.
**Answer:** C

**4. The software quality attribute of "Acceptability" dictates that:**
A) The software must be understandable, usable, and compatible with other systems used by the target users.
B) The software must not waste system resources.
C) The software must be easily updatable by any developer.
D) The software must never crash under any circumstances.
**Answer:** A

**5. In the context of software engineering challenges, what does "Heterogeneity" refer to?**
A) The need to release software faster.
B) The requirement for software to operate across diverse networks, devices, and platforms.
C) The threat of malicious attacks on the software.
D) The varying skill levels of software development teams.
**Answer:** B

**6. Which type of software is built to be adapted and customized for different customers within a specific market?**
A) Artificial intelligence software
B) System software
C) Product-line software
D) Embedded software
**Answer:** C

**7. Compilers, operating systems, and file management utilities fall under which category?**
A) Application software
B) System software
C) Web applications
D) Artificial intelligence software
**Answer:** B

**8. How is Software Engineering viewed within the broader scope of Systems Engineering?**
A) Software engineering is the superset that includes systems engineering.
B) They are entirely separate disciplines with no overlap.
C) Software is treated as a sub-system within the larger complex system designed by systems engineering.
D) Systems engineering only deals with hardware, while software engineering handles the code.
**Answer:** C

**9. When analyzing software engineering cost distribution, which phase traditionally consumes a massive, often dominant, portion of the overall budget?**
A) Initial planning
B) Coding and Development
C) Evolution/Maintenance
D) Hardware procurement
**Answer:** C

**10. Which quality attribute involves a system's ability to avoid physical or economic damage in the event of a system failure?**
A) Maintainability
B) Efficiency
C) Dependability/Security
D) Acceptability
**Answer:** C
