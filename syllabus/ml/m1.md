# Machine Learning (BCA57205)
## Module 1: Introduction to Machine Learning [8H(L) + 4H(P)]

### Syllabus Content
* **ML Principles**: Understanding machine learning, principles of machine learning, comparing machine learning with Artificial Intelligence.
* **Big Data**: Defining big data, big data in the context of machine learning, leveraging the power of machine learning.
* **Analytics**: Descriptive analytics vs. predictive analytics.
* **Practical**: Data visualization and representation using python libraries.
