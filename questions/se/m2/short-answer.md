# Short Answer Questions

**1. Define the Waterfall model and state two scenarios where its use is justified.**
**Answer:** The Waterfall model is a linear, sequential development approach where each phase (requirements, design, implementation, testing, maintenance) must be completed before moving to the next. Its use is justified in:
* Embedded systems where hardware dictates strict, unchangeable constraints.
* Large-scale, critical systems (e.g., aerospace) where comprehensive upfront documentation and rigorous safety standards are mandatory and requirements are fully understood.

**2. Differentiate between Evolutionary Development and Incremental Delivery.**
**Answer:**
* **Evolutionary Development:** Focuses on building an initial system rapidly to clarify requirements. The system evolves based on user feedback. It is often used when requirements are unclear, and the initial code may be heavily refactored or discarded (throwaway prototyping).
* **Incremental Delivery:** Focuses on delivering a fully functioning subset of the final product in planned, staggered releases. The architecture is planned upfront to accommodate future increments, and the software delivered in each increment is production-ready.

**3. What is Component-Based Software Engineering (CBSE) and what is its primary advantage?**
**Answer:** CBSE is a process model that shifts the focus from custom programming to the composition of software systems using pre-existing, reusable, and independent software components. Its primary advantage is a significant reduction in development time and cost, as integrating tested components reduces the amount of code that needs to be written and debugged from scratch.

**4. Identify three core practices of Extreme Programming (XP).**
**Answer:**
* **Pair Programming:** Two developers work together at one workstation, reviewing code continuously as it is written.
* **Test-Driven Development (TDD):** Automated unit tests are written before the production code itself.
* **Continuous Integration:** Code changes are immediately tested and merged into the main codebase, often multiple times a day.

**5. Provide a brief overview of CASE tools and explain how they support the software development process.**
**Answer:** Computer-Aided Software Engineering (CASE) tools are software applications used to automate and support various activities within the software development lifecycle. They support the process by providing features for visual modeling (UML design), automated code generation, central data dictionaries, automated testing, and version control, thereby improving productivity, consistency, and reducing human error.
