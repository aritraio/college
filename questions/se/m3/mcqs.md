# MCQs

**1. Which of the following defines what the system should do?**
A) Non-functional requirement
B) Functional requirement
C) Domain requirement
D) Feasibility study
**Answer:** B

**2. What does SRS stand for in software engineering?**
A) Software Requirement Specification
B) System Reliability Standard
C) Software Revision Strategy
D) System Requirement Schedule
**Answer:** A

**3. Which modeling tool is primarily used to represent the entities and their relationships in a database?**
A) Data Flow Diagram (DFD)
B) Data Dictionary
C) Entity-Relationship (ER) diagram
D) Use-case
**Answer:** C

**4. Performance, security, and reliability constraints are examples of:**
A) User requirements
B) Functional requirements
C) Non-functional requirements
D) System operations
**Answer:** C

**5. Which requirement elicitation technique relies on understanding the system from the perspective of different stakeholders?**
A) Scenarios
B) Viewpoints
C) Data modeling
D) Prototyping
**Answer:** B

**6. A centralized repository of information about data such as meaning, relationships to other data, origin, and usage is called a:**
A) Data Flow Diagram
B) Requirements Document
C) Database Schema
D) Data Dictionary
**Answer:** D

**7. An assessment of whether the project is technically, financially, and operationally viable before development begins is called a:**
A) Requirement validation
B) Process modeling
C) Feasibility study
D) Viewpoint analysis
**Answer:** C

**8. Which type of Data Flow Diagram (DFD) focuses on *how* the system will be implemented, including specific hardware, software, and files?**
A) Logical DFD
B) Abstract DFD
C) Conceptual DFD
D) Physical DFD
**Answer:** D

**9. A requirement that is derived from the application domain of the system and reflects the characteristics and constraints of that domain is a:**
A) Domain requirement
B) User requirement
C) Technical requirement
D) Business rule
**Answer:** A

**10. Which of the following is NOT a standard technique for requirement validation?**
A) Requirements reviews
B) Prototyping
C) Entity-Relationship modeling
D) Test-case generation
**Answer:** C
