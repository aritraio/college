# ❓ Questions Editor Scaffolding

This directory contains the Markdown files for organizing your learning materials (questions, MCQs, flashcards, etc.) across subjects and modules.

## 📁 Directory Structure
```
questions/
├── [subject_id]/           ← e.g. daa, fsd, ml, se
│   └── m[1-5]/             ← Modules m1 through m5
│       ├── mcqs.md         ← Multiple Choice Questions
│       ├── one-liner.md    ← Short single-line questions
│       ├── flashcard.md    ← Key term-to-definition cards
│       ├── long-answer.md  ← Detailed analytical questions
│       └── short-answer.md ← Brief conceptual questions
└── README.md               ← This document
```

---

## ✍️ How to Add Questions
Within each module folder (like `questions/daa/m1/`), you can edit the respective `.md` files to add or update your questions.
