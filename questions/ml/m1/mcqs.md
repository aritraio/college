# MCQs

**1. What is the primary focus of Machine Learning?**
A) Writing explicit rules for every possible scenario
B) Enabling systems to learn from data and improve from experience
C) Storing massive amounts of relational data
D) Building hardware for robots
**Answer:** B

**2. How does Machine Learning relate to Artificial Intelligence (AI)?**
A) Machine Learning is a broader concept that includes AI.
B) AI and Machine Learning are completely unrelated fields.
C) Machine Learning is a subset of AI focused on learning from data.
D) AI is purely hardware, while Machine Learning is purely software.
**Answer:** C

**3. Which of the following describes the core objective of Descriptive Analytics?**
A) Predicting future trends based on historical data
B) Summarizing past data to understand what has happened
C) Recommending actions to optimize future outcomes
D) Automating decision-making processes entirely
**Answer:** B

**4. What are the defining characteristics usually associated with Big Data?**
A) Small size, slow generation, uniform structure
B) Volume, Velocity, and Variety
C) Validity, Verification, and Value
D) Visualization, Virtualization, and Volatility
**Answer:** B

**5. In the context of Machine Learning, why is Big Data critical?**
A) It makes the algorithms run slower.
B) It allows traditional programming methods to replace ML.
C) It provides the vast amount of examples algorithms need to find patterns and train effectively.
D) It eliminates the need for data visualization.
**Answer:** C

**6. Which type of analytics would you use to forecast next month's sales based on the last five years of data?**
A) Descriptive Analytics
B) Diagnostic Analytics
C) Predictive Analytics
D) Prescriptive Analytics
**Answer:** C

**7. Which Python library is considered a fundamental tool for static data visualization and representation in ML workflows?**
A) TensorFlow
B) Scikit-learn
C) Matplotlib
D) Flask
**Answer:** C

**8. Which of the following is a fundamental principle of Machine Learning?**
A) Hardcoding logic for all edge cases
B) Generalization—the ability to perform well on unseen data
C) Memorizing the training data exactly (Overfitting)
D) Ignoring data variety to simplify the model
**Answer:** B

**9. An AI system plays chess by searching through a pre-programmed decision tree of millions of moves without learning from past games. Is this Machine Learning?**
A) Yes, because it is intelligent.
B) Yes, because it processes Big Data.
C) No, because it does not learn or improve its logic from data.
D) No, because it does not use Python.
**Answer:** C

**10. How does Machine Learning leverage the "Variety" aspect of Big Data?**
A) By forcing all data to be converted into simple text files
B) By discarding unstructured data like images and text
C) By using complex algorithms to extract features and patterns from structured, semi-structured, and unstructured data simultaneously
D) By restricting analysis to SQL databases only
**Answer:** C
