# Flashcards

**Flashcard 1**
*Front:* The Core ML Strategy Rule
*Back:* Always start with the business problem, not the technical solution.

**Flashcard 2**
*Front:* Purpose of a Pilot Project
*Back:* To mitigate risk, validate assumptions, and secure stakeholder buy-in with minimal investment.

**Flashcard 3**
*Front:* Trade-off in Determining the Best Model
*Back:* Balancing model complexity (accuracy) with business constraints (speed, interpretability, and cost).

**Flashcard 4**
*Front:* Use Case: Proactive IT
*Back:* Shifting from reactive troubleshooting to predictive maintenance using system log anomalies.

**Flashcard 5**
*Front:* Use Case: Fraud Protection
*Back:* Utilizing anomaly detection to identify deviations from normal user behavior in financial or access systems.

**Flashcard 6**
*Front:* Use Case: Patient Health
*Back:* Applying predictive algorithms to clinical data to improve diagnostic accuracy and care plans.

**Flashcard 7**
*Front:* Practical: Model Training
*Back:* The phase where the chosen algorithm learns the mapping between input features and the target variable.

**Flashcard 8**
*Front:* Practical: Prediction
*Back:* The inference phase where the trained model is applied to live data to generate business value.
