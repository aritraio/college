# Flashcards

**Flashcard 1**
*Front:* React Component
*Back:* An independent, reusable piece of the UI. Can be implemented as either a JavaScript function or an ES6 class.

**Flashcard 2**
*Front:* JSX
*Back:* JavaScript XML. A syntax extension that allows developers to write HTML directly inside JavaScript files.

**Flashcard 3**
*Front:* Embedding JS in JSX
*Back:* Wrap the JavaScript expression, variable, or logic inside curly braces `{}`.

**Flashcard 4**
*Front:* JSX Comment Syntax
*Back:* `{/* This is a comment inside JSX */}`

**Flashcard 5**
*Front:* `public/` directory
*Back:* The directory in a React app containing static assets and the root `index.html` file where the React DOM attaches.

**Flashcard 6**
*Front:* `src/` directory
*Back:* The directory where you write the core application logic, components, and CSS files.

**Flashcard 7**
*Front:* Function Component
*Back:* A standard JavaScript function that accepts arguments (props) and returns a React element (JSX).

**Flashcard 8**
*Front:* Class Component
*Back:* An ES6 class that extends `React.Component` and relies on a `render()` method to return a React element.
