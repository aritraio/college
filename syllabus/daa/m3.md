# Design and Analysis of Algorithm (BCA50113)
## Module 3: Algorithm Design Techniques [16H]

### Syllabus Content
* **Brute Force & Divide-and-Conquer**: Brute force algorithms; divide-and-conquer strategy, recursive max-min problem, matrix multiplication using divide-and-conquer, and Strassen's algorithm.
* **Greedy Techniques**: Fractional Knapsack problem, Job sequencing with deadline.
* **Dynamic Programming**: 0/1 Knapsack problem, Matrix Chain Multiplication.
* **Backtracking**: N-Queens problem.
* **String Matching**: Naive algorithm and Knuth-Morris-Pratt (KMP) algorithm.
