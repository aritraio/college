# MCQs

**1. What is the fundamental first step when formulating a machine learning strategy?**
A) Selecting the most advanced neural network
B) Gathering massive amounts of unstructured data
C) Understanding the specific business problem
D) Deploying a predictive algorithm to production
**Answer:** C

**2. What is the primary purpose of executing a pilot project in machine learning?**
A) To replace existing legacy systems immediately
B) To validate technical feasibility and business value on a small scale
C) To bypass the need for data cleaning
D) To train the entire company on machine learning skills
**Answer:** B

**3. Applying machine learning to patient health typically focuses on which of the following?**
A) Automating hospital billing systems
B) Proactively predicting disease progression or treatment outcomes
C) Managing the hospital's internal IT network
D) Encrypting patient records
**Answer:** B

**4. When proactively responding to IT issues using ML, what is the algorithm primarily looking for?**
A) Syntax errors in user-facing web applications
B) Anomalies and patterns in system logs that precede failures
C) Unauthorized physical access to server rooms
D) Outdated software licenses
**Answer:** B

**5. Determining the best learning model for a business problem requires balancing which factors?**
A) Algorithm accuracy, business constraints, and data availability
B) The popularity of the programming language and developer preference
C) Hardware costs and marketing budgets
D) The number of lines of code required
**Answer:** A

**6. Protecting against fraud is a common ML use case. Which type of problem is this usually framed as?**
A) Natural language processing
B) Anomaly detection or binary classification
C) Image recognition
D) Reinforcement learning
**Answer:** B

**7. Which of the following is a critical machine learning skill required for executing an ML strategy?**
A) Graphic design for front-end interfaces
B) Ability to translate business metrics into technical optimization targets
C) Hardware manufacturing
D) Basic spreadsheet data entry
**Answer:** B

**8. During the practical implementation of model training, what must be done to evaluate the model's true performance?**
A) Train and test the model on the exact same dataset
B) Manually adjust the predictions to fit the business expectations
C) Separate the data into distinct training and validation sets
D) Use only simulated data, never real business data
**Answer:** C

**9. If an ML prediction algorithm deployed for IT issues flags too many normal events as failures, what is the business consequence?**
A) Increased system security
B) Alert fatigue and wasted operational resources
C) Lower hardware costs
D) Better patient health outcomes
**Answer:** B

**10. A pilot project for a fraud detection system shows high accuracy but takes 10 minutes to process a single transaction. Why does this fail the overall ML strategy?**
A) The machine learning skills used were outdated
B) It fails to meet the real-time business constraints of transaction processing
C) Fraud cannot be detected by machine learning
D) The data used was biased
**Answer:** B
