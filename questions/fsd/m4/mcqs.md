# MCQs

**1. What architectural pattern does AngularJS primarily implement to separate application logic from the user interface?**
A) MVVM
B) MVC
C) Flux
D) Redux
**Answer:** B

**2. According to the syllabus, which backend technologies are used to create the API for React integration?**
A) Node.js & MongoDB
B) Python & PostgreSQL
C) PHP & MySQL
D) Java & Oracle
**Answer:** C

**3. How do you fundamentally inject an AngularJS expression into standard HTML?**
A) `[[ expression ]]`
B) `<% expression %>`
C) `{{ expression }}`
D) `<?php expression ?>`
**Answer:** C

**4. When setting up a basic AngularJS environment, what is the critical first step?**
A) Installing Node.js
B) Compiling the TypeScript files
C) Including the AngularJS JavaScript file in the HTML `<script>` tag
D) Configuring the Webpack server
**Answer:** C

**5. What is the primary purpose of data binding in AngularJS?**
A) To connect the HTML structure to the CSS stylesheet
B) To automatically synchronize data between the model and the view
C) To bind server-side databases directly to the client browser
D) To encrypt data payloads sent over HTTP
**Answer:** B

**6. Which of the following is a valid AngularJS expression for evaluating a mathematical equation?**
A) `{{ 5 + 5 }}`
B) `{ 5 + 5 }`
C) `<eval> 5 + 5 </eval>`
D) `ng-math="5 + 5"`
**Answer:** A

**7. When sending data from a React frontend to a PHP API, what data format is most standard for the payload?**
A) XML
B) Plain Text
C) JSON
D) HTML
**Answer:** C

**8. How do you correctly access the second element of an array named `colors` within an AngularJS expression?**
A) `{{ colors(2) }}`
B) `{{ colors[1] }}`
C) `{{ colors.2 }}`
D) `{{ colors[2] }}`
**Answer:** B

**9. In React API integration, what is the logical role of the `fetch()` API or a library like Axios?**
A) To execute PHP code directly in the browser
B) To act as the database engine
C) To handle HTTP requests (GET, POST) to communicate with the backend API
D) To bind data to the DOM automatically
**Answer:** C

**10. What defines "Object Binding" in AngularJS?**
A) Linking two separate HTML files together
B) Accessing and displaying properties of a JavaScript object using dot notation inside an expression
C) Binding a CSS class to a specific HTML div
D) Merging two arrays into a single object
**Answer:** B
