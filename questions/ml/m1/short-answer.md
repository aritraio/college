# Short Answer Questions

**1. Briefly explain the difference between Artificial Intelligence and Machine Learning. (3 marks)**
**Answer:** Artificial Intelligence (AI) is a broad field of computer science focused on creating systems capable of performing tasks that typically require human intelligence, such as visual perception or speech recognition. Machine Learning (ML) is a specific subset of AI. While AI can be achieved through hardcoded rules (expert systems), ML strictly involves training algorithms to learn patterns directly from data without being explicitly programmed for every scenario.

**2. Define Big Data using its primary characteristics. (3 marks)**
**Answer:** Big Data refers to datasets whose size or type is beyond the ability of traditional relational databases to capture, manage, and process. It is defined by three primary characteristics (the 3 Vs): **Volume** (the massive scale of data generated), **Velocity** (the high speed at which new data is generated and moves), and **Variety** (the different types of data, including structured, semi-structured, and unstructured data like text, audio, and video).

**3. Compare Descriptive Analytics and Predictive Analytics. (4 marks)**
**Answer:** Descriptive analytics looks backward; it aggregates historical data to summarize what happened in the past (e.g., generating a report on last quarter's sales). It provides context. Predictive analytics looks forward; it uses historical data, statistical algorithms, and machine learning to forecast what is likely to happen in the future (e.g., forecasting next quarter's sales based on past trends). Descriptive is informative, while predictive is actionable.

**4. Why is data visualization an essential practical step in Machine Learning? (3 marks)**
**Answer:** Data visualization is crucial because raw data is often incomprehensible in its tabular or raw form. Visualizing data using Python libraries helps data scientists quickly identify underlying patterns, correlations, distributions, and outliers. It is a necessary step for data cleaning, feature selection, and explaining model outcomes to non-technical stakeholders.

**5. State two core principles of Machine Learning. (2 marks)**
**Answer:** 1. **Data-Driven Logic:** Rules are derived from data rather than hardcoded by a programmer.
2. **Generalization:** A good ML model must not just memorize the training data but must generalize well to make accurate predictions on new, unseen data.
