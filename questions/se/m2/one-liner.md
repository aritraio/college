# One-Liner Questions

1. **Question:** What is a Software Process?
**Answer:** A structured sequence of activities and tasks required to develop, test, and maintain a software system.

2. **Question:** Define the Waterfall Model.
**Answer:** A linear, sequential software development life cycle model where progress flows downwards like a waterfall through distinct phases.

3. **Question:** What is Process Iteration?
**Answer:** The practice of repeating process activities to refine, improve, or adapt the software based on feedback or changing requirements.

4. **Question:** What is Evolutionary Development?
**Answer:** An approach where an initial implementation is rapidly developed, exposed to user comment, and refined through successive versions until an adequate system is produced.

5. **Question:** Define Incremental Delivery.
**Answer:** Deploying the software in portions (increments), allowing users to gain value from early releases while the rest of the system is still under development.

6. **Question:** What is the Spiral Model?
**Answer:** A risk-driven development model that combines iterative development with the systematic aspects of the waterfall model.

7. **Question:** Define Component-Based Software Engineering (CBSE).
**Answer:** A process focusing on designing and constructing software systems using reusable, independent software components.

8. **Question:** What are Agile Methods?
**Answer:** A group of software development methodologies based on iterative development, where requirements and solutions evolve through collaboration between self-organizing cross-functional teams.

9. **Question:** What is Rapid Application Development (RAD)?
**Answer:** An agile project management strategy that prioritizes rapid prototyping and quick feedback over strict, upfront planning.

10. **Question:** What are CASE Tools?
**Answer:** Automated or semi-automated software applications designed to assist in the development, maintenance, and project management of software systems.
