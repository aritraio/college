# One-Liner Questions

1. **Question:** What is Software Testing?
**Answer:** The process of executing a program with the intent of finding errors.

2. **Question:** Define Verification.
**Answer:** The process of evaluating software to determine whether the products of a given development phase satisfy the conditions imposed at the start of that phase.

3. **Question:** Define Validation.
**Answer:** The process of evaluating software during or at the end of the development process to determine whether it satisfies specified user requirements.

4. **Question:** What is Quality Assurance (QA)?
**Answer:** A systematic pattern of all actions necessary to provide adequate confidence that an item or product conforms to established technical requirements.

5. **Question:** Differentiate between Product Quality and Process Quality.
**Answer:** Product quality refers to the characteristics of the final software artifact, whereas process quality refers to the effectiveness and efficiency of the methodologies used to build the software.

6. **Question:** What is the purpose of ISO 9000?
**Answer:** It is a family of standards that defines a quality assurance system framework to ensure an organization maintains consistent processes.

7. **Question:** What is a Function Point?
**Answer:** A unit of measurement used to express the amount of business functionality an information system provides to a user.

8. **Question:** What is a Task Set in scheduling?
**Answer:** A collection of software engineering work tasks, milestones, and deliverables that must be completed to achieve a specific project goal.

9. **Question:** What is Network Scheduling?
**Answer:** A project management technique that uses a network diagram to represent the sequence and dependencies of project tasks.

10. **Question:** What does Risk Mitigation involve?
**Answer:** Proactive planning to avoid a risk entirely or to reduce its probability and impact before it occurs.
