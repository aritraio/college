# One-Liner Questions

1. **Question:** What is Software Architecture?
**Answer:** The overarching structural organization of a software system that defines its components and their interactions.

2. **Question:** Define Modularity.
**Answer:** The practice of dividing a software system into smaller, manageable, and logically distinct components (modules).

3. **Question:** What is Cohesion?
**Answer:** A measure of how strongly related and focused the responsibilities of a single module are.

4. **Question:** What is Coupling?
**Answer:** A measure of the degree of interdependence or reliance between two or more software modules.

5. **Question:** What is Functional Independence?
**Answer:** The design goal where modules have a specific, singular purpose and minimal interaction with other modules.

6. **Question:** What is UI Input Design?
**Answer:** The process of creating interfaces that allow users to enter data accurately and efficiently.

7. **Question:** List characteristics of Good UI Design Elements.
**Answer:** Characteristics like consistency, clear navigation, intuitive controls, and responsive feedback.

8. **Question:** What is the purpose of Error Messages in GUI design?
**Answer:** Clear, constructive GUI features designed to inform the user of a problem and guide them to a solution without technical jargon.

9. **Question:** What are Programming Practices?
**Answer:** Established guidelines and methodologies that developers follow to write robust, efficient, and bug-free code.

10. **Question:** Define Language Selection in software development.
**Answer:** The process of choosing a programming language based on the project requirements, architecture, available tools, and developer expertise.
