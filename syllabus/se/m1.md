# Software Engineering (BCA50112)
## Module 1: Introduction to Software Engineering [3H]

### Syllabus Content
* **Definition of Software**: The configuration components (programs, data structures, and documentation). Software deterioration vs. hardware wear-out.
* **Types of Software**: System software, application software, embedded software, product-line software, web applications, and artificial intelligence software.
* **Quality Attributes**: Characteristics and attributes of good software (maintainability, dependability/security, efficiency, and acceptability).
* **Software Engineering Concept**: Definition of software engineering, cost distribution (development vs. testing vs. evolution/maintenance). Key challenges faced by software engineers (heterogeneity, rapid delivery, security/trust).
* **Systems Engineering**: The concept of systems engineering and software as a sub-system.
