# Flashcards

**Flashcard 1**
*Front:* MVC Architecture
*Back:* A design pattern used in AngularJS that separates the application into Model (data), View (UI), and Controller (logic).

**Flashcard 2**
*Front:* React API Integration
*Back:* The process of a React frontend making HTTP requests (fetch/send) to a backend server (e.g., PHP/MySQL) to manage dynamic data.

**Flashcard 3**
*Front:* AngularJS Expressions
*Back:* Code written inside `{{ }}` that resolves to a value and outputs it directly into the HTML DOM.

**Flashcard 4**
*Front:* Data Binding (AngularJS)
*Back:* The mechanism that automatically keeps the Model (data) and View (HTML) in sync. When data changes, the UI updates, and vice versa.

**Flashcard 5**
*Front:* PHP & MySQL API
*Back:* The backend technology stack used to handle business logic (PHP) and persistent data storage (MySQL) to serve the frontend.

**Flashcard 6**
*Front:* Array Expression (AngularJS)
*Back:* Accessing specific indices of an array to display in the view, syntax: `{{ arrayName[index] }}`.

**Flashcard 7**
*Front:* Object Expression (AngularJS)
*Back:* Accessing properties of an object to display in the view, syntax: `{{ objectName.propertyName }}`.

**Flashcard 8**
*Front:* Setting up AngularJS Environment
*Back:* The fundamental process of loading the AngularJS library via a `<script>` tag and initializing the app with the `ng-app` attribute.
