# Machine Learning (BCA57205)
## Module 2: Types of Learning and its Applications [12H(L) + 12H(P)]

### Syllabus Content
* **Foundations**: The roles of statistics and data mining in machine learning.
* **Learning Paradigms**: Approaches to machine learning, supervised learning, unsupervised learning, reinforcement learning, neural networks.
* **Applications**: Applying machine learning, understanding machine learning techniques, tying machine learning methods to outcomes, applying machine learning to business needs.
* **Practical**: Data preprocessing and building/evaluating machine learning models.
