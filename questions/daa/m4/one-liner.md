# One-Liner Questions

1. **Question:** What is the definition of Breadth First Search (BFS)?
**Answer:** A graph traversal technique that explores all neighbor nodes at the present depth before moving on to the nodes at the next depth level.

2. **Question:** What is the definition of Depth First Search (DFS)?
**Answer:** A graph traversal technique that explores deeply into a branch and uses backtracking when it hits a dead end.

3. **Question:** Define a Minimum Spanning Tree (MST).
**Answer:** A subset of the edges of a connected, edge-weighted graph that connects all vertices without any cycles and with the minimum possible total edge weight.

4. **Question:** What is the focus of Dijkstra's Algorithm?
**Answer:** Solves the single-source shortest path problem for graphs where all edge weights are non-negative.

5. **Question:** What is the main utility of the Bellman-Ford algorithm?
**Answer:** Computes single-source shortest paths and is explicitly capable of handling negative edge weights and detecting negative weight cycles.

6. **Question:** Explain the approach of the Floyd-Warshall algorithm.
**Answer:** Uses dynamic programming to compute the shortest paths between all pairs of vertices in a weighted graph.

7. **Question:** What is Edge Relaxation?
**Answer:** The process of testing whether the shortest known path to a node can be improved by passing through an adjacent node, updating the cost if successful.

8. **Question:** What is a Disjoint Set data structure?
**Answer:** A data structure that keeps track of a set of elements partitioned into multiple non-overlapping subsets.

9. **Question:** Explain the execution of Prim's Algorithm.
**Answer:** Builds the MST by starting at an arbitrary node and continuously adding the lowest-weight edge that connects a node in the tree to a node outside the tree.

10. **Question:** Explain the execution of Kruskal's Algorithm.
**Answer:** Builds the MST by sorting all edges by weight and adding them sequentially to a forest, provided they do not form a cycle.
