# One-Liner Questions

1. **Question:** Define Software.
**Answer:** Software is a collection of programs, data structures, and documentation that operate together to provide desired features and functions.

2. **Question:** Explain software deterioration.
**Answer:** Software does not physically wear out like hardware; rather, it deteriorates over time as continuous changes and patches introduce new bugs and degrade its original structure.

3. **Question:** What is Artificial Intelligence software?
**Answer:** Software that makes use of non-numerical algorithms to solve complex problems that are not amenable to computation or straightforward analysis.

4. **Question:** What does the "Maintainability" attribute require?
**Answer:** It requires that software must be written in a way that allows it to evolve to meet changing customer needs.

5. **Question:** What does the "Efficiency" attribute require?
**Answer:** Software should not make wasteful use of system resources such as memory and processor cycles.

6. **Question:** Define Software Engineering.
**Answer:** It is the application of a systematic, disciplined, quantifiable approach to the development, operation, and maintenance of software.

7. **Question:** What is the "Rapid Delivery" challenge?
**Answer:** The pressure to deliver high-quality software to the market or users faster without compromising other quality attributes.

8. **Question:** What is Application Software?
**Answer:** Stand-alone programs that solve a specific business or technical need.

9. **Question:** What is the "Security/Trust" challenge?
**Answer:** Ensuring that the software is secure against malicious attacks and that users can trust it with sensitive data.

10. **Question:** Define Systems Engineering.
**Answer:** A broad discipline concerning the specification, design, and implementation of complex systems, where software is considered just one of several sub-systems.
