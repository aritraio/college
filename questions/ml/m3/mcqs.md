# MCQs

**1. What is the primary role of an algorithm in machine learning?**
A) To find patterns in data and build predictive logic
B) To store and manage databases
C) To design user interfaces for applications
D) To manually clean raw data
**Answer:** A

**2. Which phase involves cleaning, transforming, and formatting raw data before feeding it to a model?**
A) Model Deployment
B) Data Preparation
C) Model Training
D) System Evaluation
**Answer:** B

**3. What must immediately precede the actual training of machine learning systems in a pipeline?**
A) Identifying relevant data and data preparation
B) Deploying the model to production
C) Writing the front-end code
D) Evaluating the model's accuracy on a test set
**Answer:** A

**4. Which type of machine learning algorithm is designed to learn from a dataset that includes explicit labels or target outcomes?**
A) Unsupervised Learning
B) Reinforcement Learning
C) Supervised Learning
D) Dimensionality Reduction
**Answer:** C

**5. Why is "identifying relevant data" a critical component of the machine learning cycle?**
A) It permanently reduces the hardware costs of the system.
B) Algorithms learn from whatever they are fed; irrelevant data introduces noise and degrades model accuracy.
C) It allows the system to bypass the data preparation phase entirely.
D) It guarantees 100% accuracy in the final model.
**Answer:** B

**6. In a standard model pipeline, what is the logical progression of steps?**
A) Train Model -> Identify Data -> Prepare Data
B) Identify Data -> Train Model -> Prepare Data
C) Identify Data -> Prepare Data -> Train Model
D) Prepare Data -> Train Model -> Identify Data
**Answer:** C

**7. What is the purpose of the 'practical implementation' phase when working with ML algorithms?**
A) To mathematically prove the algorithm's existence on paper.
B) To translate algorithmic logic into executable code that processes datasets.
C) To manually calculate the weights and biases of a neural network.
D) To collect raw data from external sources.
**Answer:** B

**8. Which of the following best describes the iterative nature of the machine learning cycle?**
A) Data Collection -> Preparation -> Training -> Evaluation -> Iterate based on results.
B) Definition -> Algorithm Selection -> Training -> Cycle Terminates.
C) Preparation -> Training -> Deployment -> Data Deletion.
D) Algorithm Selection -> Deployment -> Training -> Evaluation.
**Answer:** A

**9. When identifying relevant data within a model pipeline, how does feature selection specifically impact the training algorithm?**
A) It changes the core mathematical equations the algorithm uses.
B) It converts unsupervised algorithms into supervised algorithms.
C) It reduces dimensionality, which can improve computational efficiency and prevent the algorithm from overfitting to noise.
D) It dictates the programming language used for the pipeline.
**Answer:** C

**10. In the context of training machine learning systems, what fundamentally occurs "inside" the algorithm during the training phase?**
A) The algorithm executes static, hardcoded rules defined by a human programmer.
B) The algorithm iteratively updates internal parameters (like weights) to minimize an error function based on the provided data.
C) The algorithm continuously searches the internet for more relevant data.
D) The algorithm generates new, unverified algorithms to test the data.
**Answer:** B
