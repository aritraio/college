# MCQs

**1. Which software process model is a sequential approach where each phase must be completed before the next begins?**
A) Agile
B) Waterfall model
C) Extreme Programming (XP)
D) Spiral model
**Answer:** B

**2. What is the fundamental definition of a software process?**
A) A specific programming language used for development.
B) A structured set of activities required to develop a software system.
C) The hardware required to run a software application.
D) A database management system.
**Answer:** B

**3. In Component-Based Software Engineering (CBSE), what is the primary emphasis?**
A) Writing all code from scratch.
B) Extensive risk analysis.
C) Maximizing the reuse of existing software components.
D) Creating throwaway prototypes.
**Answer:** C

**4. How does the Spiral model fundamentally differ from other software process models?**
A) It eliminates the need for testing.
B) It relies entirely on component reuse.
C) It is heavily risk-driven, incorporating risk analysis in every iteration.
D) It delivers the final product in a single phase.
**Answer:** C

**5. Which of the following is a core principle of Agile methods?**
A) Comprehensive documentation over working software.
B) Rigid adherence to an initial plan.
C) Individual and team interactions over processes and tools.
D) Upfront requirement gathering with no changes allowed.
**Answer:** C

**6. Incremental delivery involves:**
A) Delivering the system in parts, prioritizing the most critical functionality first.
B) Waiting until the entire system is built before showing the client.
C) Developing an initial prototype and throwing it away.
D) Automating the software process entirely with CASE tools.
**Answer:** A

**7. Extreme Programming (XP) advocates for which of the following practices?**
A) Heavy, upfront design phases.
B) Pair programming and test-driven development.
C) Avoiding customer involvement until the end.
D) Delivering updates only once a year.
**Answer:** B

**8. How are CASE (Computer Aided Software Engineering) tools typically classified?**
A) By price and licensing model.
B) By function, process support, and breadth of support (tools, workbenches, environments).
C) By the programming language they were written in.
D) By the hardware they run on.
**Answer:** B

**9. What is the primary purpose of software prototyping within Rapid Software Development?**
A) To serve as the final, production-ready code.
B) To replace thorough testing procedures.
C) To validate requirements and demonstrate concepts to stakeholders early.
**Answer:** C

**10. In the context of evolutionary development, how is the process managed compared to the Waterfall model?**
A) The specification, development, and validation phases are interleaved rather than separate.
B) It completely ignores user feedback to speed up development.
C) It strictly requires CASE tools to function.
D) It guarantees zero defects upon the first release.
**Answer:** A
