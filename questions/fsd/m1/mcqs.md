# MCQs

**1. Which of the following must be installed on your machine before you can create and run a local React JS application?**
A) Python
B) Node.js and npm
C) Apache Server
D) MySQL
**Answer:** B

**2. What is the standard command line tool/approach used to generate a new boilerplate React application?**
A) `create-new-react`
B) `npx create-react-app` (or Vite equivalents)
C) `npm install react-dom`
D) `react-start-app`
**Answer:** B

**3. What does JSX stand for in the context of React?**
A) JavaScript XML
B) JavaScript Syntax Extension
C) Java Standard XML
D) JSON Syntax Extension
**Answer:** A

**4. When writing JSX, how do you correctly apply a CSS class to an HTML element?**
A) `class="my-class"`
B) `cssClass="my-class"`
C) `className="my-class"`
D) `classId="my-class"`
**Answer:** C

**5. How do you embed a dynamic JavaScript variable into your JSX code?**
A) `${variable}`
B) `{{variable}}`
C) `<script>variable</script>`
D) `{variable}`
**Answer:** D

**6. Which folder in a standard React directory structure typically holds the `index.html` file?**
A) `src/`
B) `node_modules/`
C) `public/`
D) `components/`
**Answer:** C

**7. How do you correctly write a comment inside the `return` block of a React component (inside JSX)?**
A) ``
B) `// Comment //`
C) `{/* Comment */}`
D) `/* Comment */`
**Answer:** C

**8. Why do developers choose React JS over vanilla JavaScript for building complex user interfaces?**
A) Because it does not require HTML or CSS.
B) Because it uses a component-based architecture for code reusability.
C) Because it runs entirely on the backend server.
D) Because it inherently compiles to Java.
**Answer:** B

**9. Structurally, what is a React Functional Component?**
A) A JavaScript function that accepts props as arguments and returns React elements.
B) A JavaScript class that inherits from the DOM.
C) An HTML file that imports JavaScript.
D) A strict JSON object.
**Answer:** A

**10. What is a strict requirement for a React Class Component that is NOT required for a Function Component?**
A) It must export its code.
B) It must contain a `render()` method that returns JSX.
C) It must import CSS directly.
D) It must use Arrow Functions.
**Answer:** B
