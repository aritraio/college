# Full-stack Development II (BCA57115)
## Module 5: Working of Directives using Controllers with Filters & Services [8H(L) + 16H(P)]

### Syllabus Content
* **Directives & Controllers**: Conditional directives, understanding controllers, programming controllers, and the `$scope` object, adding behavior to a scope object with parameters.
* **Scope Inheritance**: Nested controllers and scope inheritance, multiple controllers and their scopes.
* **Filters**: Built-in filters, creating custom filters.
* **Forms & Validation**: Using simple forms, CSS classes, form events, custom validations.
* **Services**: Understanding services, creating services, using a service, injecting dependencies in a service.
* **Practical**: Implementation of scope inheritance using controllers and use of validation control.
