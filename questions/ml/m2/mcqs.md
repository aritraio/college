# MCQs

**1. Which learning paradigm relies entirely on training algorithms using labeled datasets?**
A) Unsupervised Learning
B) Reinforcement Learning
C) Supervised Learning
D) Dimensionality Reduction
**Answer:** C

**2. What is the primary objective of Unsupervised Learning?**
A) To predict a continuous output variable.
B) To discover hidden patterns or intrinsic structures in data without predefined labels.
C) To maximize a numerical reward signal.
D) To map inputs to known outputs.
**Answer:** B

**3. In the context of the syllabus foundations, how does Data Mining differ from Machine Learning?**
A) Data Mining focuses on finding patterns in existing datasets, while ML focuses on building models to predict future outcomes.
B) Data Mining is only used for structured data, whereas ML is only for unstructured data.
C) Data Mining is a subset of Supervised Learning.
D) There is absolutely no difference; they are synonymous.
**Answer:** A

**4. An algorithm that learns by interacting with its environment and receiving feedback in the form of rewards or penalties is utilizing:**
A) Supervised Learning
B) Reinforcement Learning
C) Deep Neural Networks
D) Clustering
**Answer:** B

**5. Which of the following is a crucial step in "Data Preprocessing" before building an ML model?**
A) Handling missing values and feature scaling
B) Hyperparameter tuning
C) Deploying the model to a business dashboard
D) Calculating model accuracy
**Answer:** B

**6. What represents the foundational role of statistics in machine learning?**
A) Writing the backend database architecture.
B) Providing the mathematical frameworks for probability, inference, and quantifying model uncertainty.
C) Designing the user interface of the application.
D) Managing hardware memory allocation during training.
**Answer:** B

**7. Neural networks are a learning paradigm fundamentally inspired by:**
A) The biological structures of the human brain, utilizing interconnected nodes (neurons).
B) Linear algebra matrices without any activation functions.
C) Purely random trial-and-error mechanisms.
D) Classical database indexing structures.
**Answer:** A

**8. When tying machine learning methods to business outcomes, which metric is practically more important to business stakeholders than pure model accuracy?**
A) The number of hidden layers in the model.
B) The computational time taken to train the model.
C) Return on Investment (ROI) and alignment with key performance indicators (KPIs).
D) The programming language used to build the model.
**Answer:** C

**9. During the model evaluation phase, why is testing data kept completely separate from training data?**
A) To speed up the compilation of the code.
B) To prevent the model from simply memorizing the answers, allowing for a true test of its generalization ability on unseen data.
C) Because machine learning algorithms cannot process more than one dataset at a time.
D) To artificially inflate the model's performance metrics.
**Answer:** B

**10. You are applying ML to a business need: predicting customer churn. Your dataset has 95% retained customers and 5% churned customers. Which evaluation metric will give you the most brutally honest assessment of your model's performance?**
A) Overall Accuracy
B) F1-Score or Precision/Recall
C) Mean Absolute Error
D) R-squared
**Answer:** B
