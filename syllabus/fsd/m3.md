# Full-stack Development II (BCA57115)
## Module 3: User Input Forms with Events and Deployment [6H(L) + 12H(P)]

### Syllabus Content
* **Arrow Functions**: React arrow functions.
* **Form Handling**: Creating and handling user input forms, creating event handlers.
* **Developer Tools**: Free React developer tools.
* **Deployment**: Deploying a React application on a server.
* **Practical**: Implementation of React arrow functions, handling forms, creating event handlers, using developer tools, and deploying a React application to a server.
