# Software Engineering (BCA50112)
## Module 2: Software Development Process Models [10H]

### Syllabus Content
* **Software Process & Models**: The software process, software process models, and the Waterfall model.
* **Evolutionary & Iterative Models**: Evolutionary development, process iteration, incremental delivery, and spiral development.
* **Component-Based Software Engineering**: Overview of CBSE.
* **Rapid Software Development & Agile**: Agile methods, Extreme Programming (XP), Rapid Application Development (RAD), and software prototyping.
* **CASE Tools**: Computer Aided Software Engineering (CASE), overview of CASE approaches, and classification of CASE tools.
