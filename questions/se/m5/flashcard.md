# Flashcards

**Flashcard 1**
*Front:* Verification vs. Validation
*Back:* 
* **Verification:** "Are we building the product right?" (Checking against specifications).
* **Validation:** "Are we building the right product?" (Checking against user needs).

**Flashcard 2**
*Front:* Black-Box Testing
*Back:* Testing that ignores the internal mechanism of a system and focuses solely on the outputs generated in response to selected inputs and execution conditions.

**Flashcard 3**
*Front:* White-Box Testing
*Back:* Testing that takes into account the internal structural logic of the software, requiring the tester to design test cases based on the source code.

**Flashcard 4**
*Front:* Capability Maturity Model (CMM)
*Back:* A framework that describes an evolutionary improvement path for software organizations from an ad hoc, immature process to a mature, disciplined one.

**Flashcard 5**
*Front:* COCOMO II
*Back:* Constructive Cost Model II; an algorithmic software cost estimation model that uses historical data, project characteristics, and size estimates to predict effort and duration.

**Flashcard 6**
*Front:* Earned Value Analysis
*Back:* A quantitative technique used in project management to assess schedule and cost performance throughout the project lifecycle.
