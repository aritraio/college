# One-Liner Questions

1. **Question:** Define P Class.
**Answer:** The set of decision problems that can be solved by a deterministic algorithm in polynomial time, $O(n^k)$.

2. **Question:** Define NP Class.
**Answer:** The set of decision problems where a given solution can be verified as correct by a deterministic algorithm in polynomial time.

3. **Question:** Define NP-Complete.
**Answer:** A class of problems in NP to which all other NP problems can be polynomially reduced; the hardest problems in NP.

4. **Question:** What is Boolean Satisfiability (SAT)?
**Answer:** The problem of determining if there exists an interpretation that satisfies a given boolean formula.

5. **Question:** What is a Hamiltonian Path?
**Answer:** A path in an undirected or directed graph that visits every vertex exactly once.

6. **Question:** What is a Hamiltonian Cycle?
**Answer:** A Hamiltonian path that is a closed loop, meaning the last vertex is connected back to the first vertex.

7. **Question:** Define Vertex Cover.
**Answer:** A subset of vertices in a graph such that every edge is incident to at least one vertex in this subset.

8. **Question:** State Cook's Theorem.
**Answer:** A foundational theorem proving that the Boolean Satisfiability Problem (SAT) is NP-Complete.

9. **Question:** Define Approximation Algorithm.
**Answer:** An algorithm used to find approximate, near-optimal solutions to optimization problems (usually NP-hard) in polynomial time.

10. **Question:** Define Polynomial Reduction.
**Answer:** A method of transforming one problem into another in polynomial time, establishing that the second problem is at least as hard as the first.
