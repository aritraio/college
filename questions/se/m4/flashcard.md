# Flashcards

**Flashcard 1**
*Front:* Abstraction
*Back:* Extracting essential characteristics while ignoring irrelevant background details.

**Flashcard 2**
*Front:* Refinement
*Back:* The top-down process of elaborating abstractions into detailed implementation instructions.

**Flashcard 3**
*Front:* Information Hiding
*Back:* Restricting access to internal module details (data/algorithms) to prevent unintended external interference.

**Flashcard 4**
*Front:* High Cohesion
*Back:* All elements within a module work closely together to achieve a single, specific function.

**Flashcard 5**
*Front:* Low Coupling
*Back:* Modules have minimal reliance on each other, reducing the ripple effect of changes.

**Flashcard 6**
*Front:* Modern GUI Features
*Back:* Menus, scroll bars, windows, buttons, icons, panels, and error messages.

**Flashcard 7**
*Front:* Coding Standards
*Back:* Uniform rules for naming, formatting, and documenting code to ensure team consistency.

**Flashcard 8**
*Front:* Design Patterns
*Back:* Proven, reusable templates applied to solve common architectural and design problems.
