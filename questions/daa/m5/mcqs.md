# MCQs

**1. Which of the following best defines the complexity class P?**
A) Problems solvable in exponential time.
B) Problems solvable by a deterministic Turing machine in polynomial time.
C) Problems that cannot be solved by any computer.
D) Problems whose solutions can only be verified in polynomial time.
**Answer:** B

**2. What is the defining characteristic of problems in the NP class?**
A) They are Not Possible to solve.
B) Their solutions can be verified in polynomial time by a deterministic Turing machine.
C) They require Non-Polynomial time to solve.
D) They are optimally solved using greedy algorithms.
**Answer:** B

**3. In the context of complexity theory, what does SAT stand for?**
A) Standard Algorithm Testing
B) Satisfiability Problem
C) Boolean Satisfiability Problem
D) Systematic Array Traversal
**Answer:** C

**4. According to Cook's Theorem, which of the following was the first problem proven to be NP-Complete?**
A) Hamiltonian Path
B) Vertex Cover
C) Boolean Satisfiability Problem (SAT)
D) Traveling Salesperson Problem
**Answer:** C

**5. A problem is classified as NP-Complete if it is in NP and:**
A) It can be solved in linear time.
B) Every problem in NP can be reduced to it in polynomial time.
C) It has an exact approximation algorithm.
D) It cannot be verified in polynomial time.
**Answer:** B

**6. Which of the following is true regarding a Hamiltonian Path?**
A) It visits every edge in a graph exactly once.
B) It visits every vertex in a graph exactly once.
C) It must start and end at the same vertex.
D) It is a problem exclusively in the P class.
**Answer:** B

**7. How does a Hamiltonian Cycle differ from a Hamiltonian Path?**
A) A cycle visits every edge; a path visits every vertex.
B) A cycle must start and end at the exact same vertex, forming a closed loop.
C) A cycle allows revisiting vertices; a path does not.
D) There is no difference; the terms are interchangeable.
**Answer:** B

**8. If someone successfully proves that $P = NP$, what does this mathematically imply?**
A) All NP-Complete problems can be solved in polynomial time.
B) No NP problems can be solved.
C) Approximation algorithms are no longer useful.
D) Turing machines are obsolete.
**Answer:** A

**9. What is the primary purpose of an Approximation Algorithm?**
A) To find the absolute worst-case scenario of an algorithm.
B) To find a near-optimal solution for an NP-Hard/NP-Complete problem in polynomial time.
C) To convert a P class problem into an NP class problem.
D) To estimate the execution time of a program.
**Answer:** B

**10. Which problem asks for the minimum sized set of vertices such that every edge in the graph is connected to at least one vertex in the set?**
A) Maximum Clique
B) Hamiltonian Cycle
C) Vertex Cover
D) Graph Coloring
**Answer:** C
