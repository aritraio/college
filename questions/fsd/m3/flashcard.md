# Flashcards

**Flashcard 1**
*Front:* React Arrow Function Syntax
*Back:* `const functionName = (parameters) => { // logic }`

**Flashcard 2**
*Front:* React Event Naming Convention
*Back:* camelCase (e.g., `onClick`, `onChange`, `onSubmit`)

**Flashcard 3**
*Front:* `event.preventDefault()`
*Back:* A method called inside an event handler to stop the browser's default behavior, such as reloading the page when a form is submitted.

**Flashcard 4**
*Front:* Controlled Component
*Back:* An input form element whose value is controlled strictly by React state.

**Flashcard 5**
*Front:* React Developer Tools
*Back:* A browser extension that provides "Components" and "Profiler" tabs to inspect and debug React applications.

**Flashcard 6**
*Front:* Production Build
*Back:* The optimized, minified, and bundled version of a React application ready for server deployment.
