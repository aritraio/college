# One-Liner Questions

1. **Question:** What is inline styling in React?
**Answer:** Applying CSS properties directly to a JSX element using a JavaScript object with camelCased keys.

2. **Question:** Define a CSS Module.
**Answer:** A CSS file where all class names and animations are scoped locally by default to the component that imports it.

3. **Question:** What is the concept behind `styled-components`?
**Answer:** A CSS-in-JS library that allows developers to write actual CSS syntax inside JavaScript files to style React components.

4. **Question:** How do you add the React Bootstrap package to a project?
**Answer:** By installing the `react-bootstrap` and `bootstrap` packages via a package manager (like npm or yarn) and importing the components.

5. **Question:** What is the command to install the routing library for React?
**Answer:** `npm install react-router-dom` (or using yarn).

6. **Question:** What is the core function of React Router?
**Answer:** To enable dynamic client-side navigation and map different URLs to specific React components without reloading the page.

7. **Question:** Define the concept of props.
**Answer:** Props (properties) are read-only objects used to transfer data from a parent component down to a child component.

8. **Question:** Why do we create reusable components?
**Answer:** To adhere to the DRY (Don't Repeat Yourself) principle, maintaining consistency and reducing code duplication across the UI.

9. **Question:** State one absolute rule of working with state.
**Answer:** You must never mutate state directly; it must only be updated using its designated setter function.

10. **Question:** What is the purpose of the `react-table` package?
**Answer:** It is a lightweight, extensible library utilized to create and manage complex data tables and grids in React.
