# One-Liner Questions

1. **Question:** What does MVC stand for in AngularJS?
**Answer:** Model-View-Controller.

2. **Question:** What is the main function of an API in a React application?
**Answer:** It serves as the bridge to fetch data from or send data to the backend server.

3. **Question:** What database is paired with PHP in this module for API creation?
**Answer:** MySQL.

4. **Question:** Define an AngularJS expression.
**Answer:** A JavaScript-like code snippet written inside double braces `{{ }}` used to output data directly to the HTML view.

5. **Question:** What is data binding?
**Answer:** The automatic synchronization of data between a web application's Model (data) and its View (UI).

6. **Question:** Give an example of a string expression in AngularJS.
**Answer:** `{{ "Hello " + "World" }}`

7. **Question:** How do you access an object property named `age` from an object `user` in AngularJS?
**Answer:** `{{ user.age }}`

8. **Question:** What are AngularJS attributes commonly referred to as?
**Answer:** Directives (e.g., `ng-app`, `ng-model`).

9. **Question:** What is required to make an HTML document an AngularJS application?
**Answer:** The `ng-app` directive.

10. **Question:** In API integration, what action represents "sending data"?
**Answer:** Making an HTTP POST or PUT request from React to the backend server.
