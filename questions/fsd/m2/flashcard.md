# Flashcards

**Flashcard 1**
*Front:* Inline Styling Syntax
*Back:* Passed as a JavaScript object with camelCased keys. Example: `style={{ backgroundColor: 'blue', fontSize: '14px' }}`

**Flashcard 2**
*Front:* CSS Modules Benefit
*Back:* Prevents global style leaks. Generates unique class names at build time, ensuring CSS only applies to the specific component importing it.

**Flashcard 3**
*Front:* React Router: `<Route>`
*Back:* The component that dictates which UI component should be rendered when the application's URL matches the specified `path` prop.

**Flashcard 4**
*Front:* Props vs. State (Concept)
*Back:* Props are immutable (read-only) and passed from the outside. State is mutable and managed internally by the component itself.

**Flashcard 5**
*Front:* React Bootstrap Advantage
*Back:* Replaces Bootstrap's jQuery and JavaScript plugins with pure React components, optimizing performance and state management.

**Flashcard 6**
*Front:* Props Validation
*Back:* A mechanism to specify the required data types (string, number, array, etc.) for props to catch bugs early, often implemented using `PropTypes`.
