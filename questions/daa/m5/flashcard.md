# Flashcards

**Flashcard 1**
*Front:* Class P
*Back:* Problems solvable by a deterministic algorithm in polynomial time. Considered "tractable" or easy to solve.

**Flashcard 2**
*Front:* Class NP
*Back:* Problems whose proposed solutions can be *verified* in polynomial time. "Nondeterministic Polynomial time."

**Flashcard 3**
*Front:* Cook's Theorem
*Back:* States that the Boolean Satisfiability Problem (SAT) is NP-Complete. It provided the first benchmark for NP-Completeness.

**Flashcard 4**
*Front:* Vertex Cover Problem
*Back:* Given a graph, finding the minimum number of vertices needed to touch every single edge in the graph. It is NP-Complete.

**Flashcard 5**
*Front:* Approximation Ratio
*Back:* The metric used to measure how close an approximation algorithm's output is to the absolute optimal solution.

**Flashcard 6**
*Front:* Hamiltonian Cycle vs. Path
*Back:* Both visit every vertex exactly once, but the Cycle must return to the starting vertex, forming a closed loop. Both are NP-Complete.
