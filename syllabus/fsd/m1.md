# Full-stack Development II (BCA57115)
## Module 1: React JS and JSX with Component [4H(L) + 8H(P)]

### Syllabus Content
* **Introduction**: Prerequisites of React JS, why use React JS, software and description, installation, creating a React app.
* **JSX**: Converting HTML to JSX, file and directory structure of a React project, code snippets, JavaScript variables in JSX, comments.
* **Components**: Class component vs. function component.
* **Practical**: Installation of React JS, implementation of creating a React app, converting HTML to JSX, exploring the directory structure, writing Javascript variables in JSX, adding comments, and creating class/function components.
